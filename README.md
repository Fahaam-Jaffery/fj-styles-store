# 🇬🇧 F&J Styles — Modern Editorial Storefront

A high-end, dark-themed digital flagship boutique and e-commerce prototype built for a UK-based clothing brand. 

## 🚀 The Vibecoding Story
This project was architected, designed, and coded entirely through AI-assisted **"vibecoding"** using **Grok by xAI**. What usually takes weeks of manual front-end development was brought from concept to a fully responsive, production-ready prototype in under 20 minutes.

## ✨ Key Features
- **Dark Editorial UI:** Sleek, high-fashion aesthetic tailored for modern apparel brands.
- **Smart Catalog & Filtering:** Dynamic sorting options across women, men, and kids collections.
- **Interactive Product Variants:** Real-time color and size selection for individual apparel items.
- **Multi-Category Showcases:** Dedicated layouts for accessories, fragrances, and seasonal essentials.
- **Engagement Tools:** Fixed bottom-right interactive offer bell and subscription modal for latest arrivals.
- **Fully Responsive:** Seamlessly adapts across desktop, tablet, and mobile viewport layouts.

## 🛠️ Tech Stack
- Built with modern web frameworks and styling tokens.
- Structured component architecture optimized for fast deployment.
